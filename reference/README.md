# Referência

Arquivos da versão anterior, para consulta. Não são usados pelo site.

- `compute2_original.py`: script que gerou o histórico e as tabelas até out/2026. A lógica de
  janelas e risco foi portada para `public/assets/js/dados.js`; `tests/dados.test.js` confere
  que os números batem.
- `acoes-etfs_estatico.html`: o comparador como era antes, com os dados embutidos. Útil para
  comparar visual e textos. (O simulador antigo não entrou: tinha exemplos com dados pessoais.)

Os caminhos dentro de `compute2_original.py` apontam para a máquina onde ele rodou; ele não roda aqui.
